Bot: Qual é o custo base do produto?
Usuário: 100
Bot: Qual o percentual de custos operacionais?
Usuário: 10
Bot: Qual o percentual de impostos?
Usuário: 15
Bot: Qual a margem de lucro desejada?
Usuário: 20
Bot: O preço final do produto é R$ 153,85
